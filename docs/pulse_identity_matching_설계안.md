# Pulse Identity Matching — 전체 설계안

> "나를 가장 잘 아는 AI와, 나를 가장 잘 이해하는 사람. 두 가지가 동시에 시작됩니다."

---

## 개념 정의

베타 신청자가 랜딩에서 AI 성향 진단을 받고,  
그 결과를 기반으로 나에게 맞는 Pulse 코치가 연결되는 구조.

**핵심 경험 설계:**  
"처음부터 나한테 맞게 세팅된다"는 느낌 자체가  
The Pulse의 첫 번째 가치 증명이 된다.

---

## 전체 플로우

```
랜딩 CTA 클릭
    ↓
5분 AI 성향 진단 (이름 + 이메일 수집)
    ↓
Pulse 유형 결과 발행 (공유 가능한 카드)
    ↓
유형별 코치 매칭 안내
    ↓
30분 첫 대화 예약 (베타 무료)
    ↓
이후 앱 / 워크북으로 연결
```

---

## STEP 1 — 랜딩 CTA 문구

### 버튼 메인 텍스트
```
나의 Pulse 유형 알아보기  →
```

### 버튼 아래 보조 문구
```
5분 진단 후 나에게 맞는 코치가 연결됩니다.
베타 선착순 00명 · 무료
```

> **설계 원칙:**  
> "신청하기"보다 "알아보기"가 클릭 저항이 낮다.  
> 사람은 무언가를 받는 것보다 **나를 발견하는 것**에 먼저 반응한다.

---

## STEP 2 — AI 성향 진단 (5분, 5~7문항)

TCI + VAK 기반이지만 **심리검사처럼 보이면 안 된다.**  
일상 언어로 된 선택지로 구성.

### 문항 구성

**Q1. 지금 나에게 더 가까운 문장은?**
- A. 하고 싶은 게 많은데, 뭘 먼저 해야 할지 모르겠다
- B. 방향은 있는데, 실제로 움직이는 게 잘 안 된다

**Q2. 목표가 흐릿해지는 순간은?**
- A. 너무 많은 선택지 앞에 섰을 때
- B. 잘 가고 있는 건지 확신이 없을 때

**Q3. 나를 움직이게 하는 건?**
- A. 머릿속에 선명한 그림이 그려질 때 (Visual)
- B. 누군가 "이렇게 해봐"라고 말해줄 때 (Auditory)
- C. 몸이 먼저 움직이고 나중에 납득될 때 (Kinesthetic)

**Q4. 지금 가장 걸리는 것 하나를 고른다면?**
- A. 내가 진짜 원하는 게 뭔지 모르겠다
- B. 원하는 건 아는데 나를 못 믿겠다
- C. 알고 믿는데 지속이 안 된다

**Q5. 혼자 있을 때 당신은?**
- A. 새로운 아이디어를 구상하고 있다
- B. 지금 하는 일들을 점검하고 있다

### 이메일 수집 타이밍
> 문항 종료 후 결과 화면 직전에 이름 + 이메일 입력.  
> "진단 결과를 받기 위해" 라는 맥락이 형성되어 있으므로 입력 저항 최소화.

## STEP 3 — Pulse 유형 결과 발행

### 유형 구성 (4가지)

#### 🔷 탐색자형 (Explorer)
> "원하는 게 많고 감도 좋은데, 방향이 자꾸 바뀐다.  
> 에너지는 넘치는데 한 곳으로 모이지 않는 타입."

→ 당신에게 필요한 건 더 많은 정보가 아니라  
   **하나의 축을 잡는 것**입니다.

---

#### 🔶 정착자형 (Settler)
> "방향은 보이는데 오늘이 달라지지 않는다.  
> 알고 있지만 몸이 따라오지 않는 타입."

→ 당신에게 필요한 건 더 강한 의지가 아니라  
   **더 영리한 구조**입니다.

---

#### 🔹 탐색자형 (Seeker)
> "내가 원하는 게 맞는지 자꾸 의심된다.  
> 열심히 하는데 왜인지 항상 뭔가 어긋난 느낌."

→ 당신에게 필요한 건 더 많은 노력이 아니라  
   **진짜 나를 먼저 읽는 것**입니다.

---

#### 🔸 실행자형 (Builder)
> "목표도 있고 의지도 있는데 지속이 문제다.  
> 시작은 잘 하는데 3주를 못 넘기는 타입."

→ 당신에게 필요한 건 더 높은 목표가 아니라  
   **끊기지 않는 시스템**입니다.

---

### 결과 카드 하단 구성
```
[📷 이미지 저장]   [인스타 공유]       ← 바이럴 포인트
[내 유형에 맞는 코치 연결받기 →]
```

> **바이럴 설계:**  
> 결과 카드를 저장·공유할 수 있게 만들면  
> MBTI처럼 자연 확산 루프가 형성된다.

---

## STEP 4 — 코치 매칭 안내

### 화면 구성

```
탐색자형에게 가장 잘 맞는
Pulse 코치를 연결합니다.
```

**코치 프로필 카드**
```
심리학 기반 · 정체성 설계 전문

"같은 유형의 분들이 가장 많이 전환된
 시작점을 함께 찾아드립니다."
```

**CTA 버튼**
```
→ 코치와 첫 번째 대화 예약하기
   (베타 기간 무료 · 30분)
```

---

### 핵심 메시지 (카드 하단 고정)

```
AI가 당신의 패턴을 읽고,
사람이 첫 번째 방향을 잡아줍니다.

두 가지가 동시에 시작됩니다.
```

## 운영 가이드 (베타 단계)

| 항목 | 베타 단계 | 이후 확장 |
|------|-----------|-----------|
| 코치 | 창업자 1인 직접 운영 | 유형별 전문 코치풀 구성 |
| 진단 방식 | 웹 폼 (Google Form 또는 Typeform) | 앱 내 AI 진단 플로우 |
| 결과 카드 | 이미지 파일 4종 제작 | 동적 생성 (사용자명 삽입) |
| 예약 도구 | 캘린들리(Calendly) 또는 구글 캘린더 | 인앱 예약 시스템 |

> **베타 운영 핵심 원칙:**  
> 창업자가 직접 대화한다는 것 자체가  
> 초기에 가장 강력한 신뢰 자산이다.  
> 규모보다 깊이를 먼저.
