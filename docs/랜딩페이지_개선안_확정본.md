## 1. 공감 멘트 — "방향도 어긋난 사람" 포함

### 적용 위치
- **히어로 서브카피:** 옵션 A 사용
- **섹션 4 (문제 공감 섹션):** 옵션 D 리스트 사용

---

### 히어로 서브카피 (옵션 A — 추천)

```
열심히 살고 있는데,
이게 내 삶인지 확신이 없다.
```

> **선택 이유:**  
> "방향이 없다"도, "의지가 약하다"도 아닌  
> **확신의 부재**를 짚는다.  
> 가장 넓은 타깃에 공명하면서도 The Pulse의 철학(정체성 설계)과 자연스럽게 연결된다.

---

### 섹션 4 문제 공감 리스트 (옵션 D — 추천)

```
혹시 이런 적 있으신가요?

· 목표를 세웠는데, 그게 진짜 내 목표인지 의심된다
· 열심히 하는데 뭔가 계속 어긋나는 느낌이 든다
· 잘 살고 싶은데, '잘'이 어떤 건지 그림이 안 잡힌다
· 작년에도, 재작년에도 비슷한 자리에 있다
```

> **선택 이유:**  
> 방향 혼란 + 실행 단절 + 자기 불신을 모두 포함.  
> "나 얘기다"라는 반응이 나오는 구체성이 있으면서  
> "실패"라는 직접적 표현을 쓰지 않아 거부감이 없다.

---

### 섹션 2 창업자 스토리 끝 문장 (추가 권장)

```
그래서 이 시스템은,
내가 원하는 삶이 뭔지 모르는 사람부터
알면서도 오늘이 달라지지 않는 사람까지
모두를 위해 설계되었습니다.
```

> 기존 "나 자신을 위해 만들었습니다" 섹션의 자연스러운 마무리로 사용.

## 2. 6개 도구 — 가로 스크롤 카드 방식 (옵션 B — 추천)

### 적용 방식

모바일 기준 **가로 스와이프 카드 6장**.  
한자 아이콘 + 영문 키워드 비주얼은 유지하되,  
각 카드에 기능 설명과 실생활 변화 예시 문장 추가.

---

### 섹션 타이틀

```
하나의 시스템, 여섯 개의 층.
```

---

### 카드 구성 (6장)

| No. | 한자 | 영문 | 기능 | 내 삶에서 |
|-----|------|------|------|-----------|
| 01 | 感 | SENSE | 나의 반응 패턴 인식 | "왜 이 상황에서 항상 멈추는지" 보이기 시작합니다 |
| 02 | 性 | CORE | 핵심 정체성 정의 | "내가 진짜 원하는 것"이 한 문장으로 잡힙니다 |
| 03 | 望 | STAGE | 지금 내 위치 파악 | 막연한 불안이 구체적인 좌표로 바뀝니다 |
| 04 | 結 | CONTRACT | 미래 자아와의 계약 | 결심이 아닌 계약. 어기면 잃는 것이 생깁니다 |
| 05 | 蓄 | BANK | 에너지와 행동 누적 | 오늘 한 일이 사라지지 않고 쌓이는 구조가 생깁니다 |
| 06 | 我 | APEX | 완성된 나의 상태 | 5년 뒤의 내가 오늘 이 선택을 보고 있습니다 |

> **선택 이유:**  
> 기존 한자 비주얼의 매력을 살리면서  
> 6개가 실제로 존재한다는 것을 사용자가 탐색할 수 있게 됨.  
> 모바일에서 스와이프 인터랙션으로 자연스럽게 체류 시간 증가.

## 3. 사회적 증거 — 숫자 대신 "검증된 과학" (배지형 — 추천)

### 적용 위치
히어로 바로 아래 또는 도구 섹션 상단.

---

### 배지 3개 구성 (추천)

```
🔬 심리학 기반
TCI 성격 진단 + BPS 이론을 통합 적용

🧠 뇌과학 검증
Mental Bank — 50년 임상 데이터가 쌓아온 잠재의식 설계 원리

🇰🇷 한국형 재설계
해외 연구 기반을 한국인의 언어와 사고 패턴에 맞게 재구성
```

> **선택 이유:**  
> "미국에서 검증된"이라는 표현은 올드하고 권위주의적으로 읽힌다.  
> 대신 "50년 임상 원리를 한국형으로 재설계"라는 프레임이  
> **최신성 + 신뢰성을 동시에** 전달한다.  
> 설명 없이 아이콘 3개만으로도 "근거 있는 서비스"가 전달됨.

---

### 섹션 제목으로 쓸 수 있는 카피 (선택)

```
오래된 원리를 오늘의 언어로.
```

또는

```
검증된 과학. 한국에 맞게.
```
