톤앤보이스 가이드

> **"고요한 권위"**
> 시적이고, 스며들고, 격조 있으며, 따뜻한.
> 평행세계의 가장 완성된 내가, 조용히 말을 건네는 톤.

---

## 1. 톤 정체성

### 이름: **고요한 권위 (Quiet Authority)**

이 서비스의 화자는 "기업"이 아닙니다.
**평행세계에서 가장 바람직한 삶을 사는 또 다른 당신**입니다.

그 존재는 이렇게 말합니다:

- 조용하지만 확신이 있습니다.
- 설명하지 않고 선언합니다.
- 강요하지 않지만 흔들리지 않습니다.
- 따뜻하지만 가볍지 않습니다.
- 시적이지만 모호하지 않습니다.

### 핵심 형용사 5개

```
시적인     — 문장이 읽히는 것이 아니라 스며든다
격조 있는  — 가볍지 않다. 무게감이 있다
따뜻한     — 차갑지 않다. 손 내미는 존재다
권위 있는  — 흔들리지 않는 확신이 있다
고요한     — 소란스럽지 않다. 여백이 말한다
```

### 화자의 태도

```
"나는 당신이 될 수 있는 가장 완성된 모습입니다.
 당신에게 명령하지 않습니다.
 다만 이미 알고 있는 것을 상기시킵니다.
 조용히, 확신을 담아."
```

## 2. 문체 규칙

### 2-1. 기본 종결어미: **~합니다 / ~입니다**

본문 텍스트의 기본 톤입니다.
"~요" 체보다 무게감이 있고, 격식 있되 차갑지 않습니다.

```
✅ "순서가 달랐을 뿐입니다."
✅ "목표보다 정체성이 먼저입니다."
✅ "오늘의 당신에게 연결하는 도구입니다."

❌ "순서가 달랐을 뿐이에요."        → 가볍다
❌ "정체성이 먼저예요."             → 가볍다
❌ "연결하는 도구입니다!"           → 느낌표 금지
```

### 2-2. 적절한 "~하세요" 혼용

전체가 "~합니다"로만 이루어지면 딱딱해집니다.
**흐름의 전환점**, 특히 **행동을 권하는 순간**에 "~하세요"를 넣습니다.

```
[본문] 평행세계의 당신이 기다리고 있습니다.
[전환] 지금, 첫 번째로 만나보세요.        ← 여기서 "~하세요"

[본문] 변화의 궤적이 눈에 보이기 시작합니다.
[전환] 거울을 들여다보세요.               ← 여기서 "~하세요"
```

**비율 가이드:**

```
~합니다/입니다  :  ~하세요  =  약 8 : 2
```

### 2-3. 섹션 제목: 체언 종결 + 문학적 선언

섹션 제목은 **명사로 끝나거나, 짧은 선언형 문장**으로 씁니다.
서술어가 있을 경우에도 "~합니다" 대신 **"~다" 체**를 허용합니다.
제목은 대화가 아니라 **선언**이기 때문입니다.

```
✅ "6개의 도구, 하나의 방향."              체언 종결
✅ "순서가 달랐을 뿐."                    미완결 여운
✅ "안을 들여다보면."                      조건절 종결 (여운)
✅ "목표보다 정체성이 먼저다."              선언체
✅ "평행세계의 나는 이미 답을 알고 있다."    선언체

❌ "6개의 강력한 도구를 만나보세요!"        마케팅체
❌ "도구를 소개합니다"                     설명체
```

### 2-4. 히어로 헤드라인: "~하라" 1회 허용

전체 서비스에서 **단 한 문장**만 "~하라"를 씁니다.
히어로 메인 카피입니다.
이 한 문장은 반말이 아니라 **선언이자 소환의 주문**입니다.

```
✅ "미래의 나를 오늘로 소환하라."

이 한 문장 이후로는 다시 "~합니다" 체로 돌아갑니다.
"~하라"의 힘은 희소할 때 생깁니다.
```

### 2-5. 물음표 사용: 아껴서, 무겁게

물음표는 **진짜 질문일 때만** 씁니다.
수사적 질문도 가능하지만, 한 섹션에 하나만.

```
✅ "원하는 삶은 그려지는데, 왜 오늘은 달라지지 않는 걸까."
   (마침표로 끝내도 됩니다. 질문이지만 이미 답을 아는 듯한 톤.)

✅ "왜 오늘은 달라지지 않는 걸까요?"
   (물음표를 쓸 경우, 이 한 문장에만.)

❌ "목표 세우기 어렵지 않으셨나요? 루틴 만들기 힘드셨죠?"
   (연속 질문 = 세일즈)
```

## 3. 단어 선택 규칙

### 3-1. 사용하는 단어

```
존재합니다        (있습니다 보다 무게감)
연결합니다        (연결해요 보다 격조)
시작됩니다        (시작돼요 보다 정중)
마주하게 됩니다    (만나게 돼요 보다 깊이)
스며듭니다        (변합니다 보다 시적)
되어갑니다        (변해갑니다 보다 내면적)
정의합니다        (정합니다 보다 정확)
증명합니다        (보여줍니다 보다 무게)
확인합니다        (체크합니다 보다 격조)
기다리고 있습니다  (있어요 보다 무게감)
```

### 3-2. 피하는 단어

```
❌ "강력한" "획기적인" "최고의"     → 마케팅 수식어
❌ "쉽게" "간편하게" "빠르게"       → 가벼운 편의성 언어
❌ "무료" "할인" "혜택"            → 세일즈 언어
❌ "지금 바로"                     → 급박한 압박
❌ "완벽한"                        → 과장
❌ "단순한"                        → 서비스의 깊이를 훼손
❌ "스마트한" "혁신적인"            → 테크 버즈워드
```

### 3-3. Milestones 고유 어휘

서비스만의 세계관을 만드는 단어들입니다.

```
소환        — 미래의 나를 불러오는 행위
평행세계     — 가장 바람직한 내가 사는 곳
정체성      — 목표 이전에 먼저 정의해야 하는 것
방향        — 목표보다 상위의 개념
실행        — 습관보다 무게 있는 단어
되어감      — 결과가 아닌 과정
마일스톤    — 인생의 이정표
거울        — 성장을 확인하는 도구
계약        — 미래의 나와의 약속
축(軸)      — 나의 중심, 흔들리지 않는 것
```

## 4. 문장 구조 규칙

### 4-1. 짧게. 끊어서. 여백으로.

한 문장은 **가능하면 20자 이내**.
줄바꿈이 곧 호흡입니다.

```
❌ 한 덩어리:
"Milestones Today는 흩어진 목표를 정체성으로 묶고 오늘의 실행으로 연결하는 라이프 디자인 앱입니다."

✅ 끊어서:
"흩어진 목표를 정체성으로 묶고,
 오늘의 실행으로 연결합니다."
```

### 4-2. 주어를 줄인다

서비스 이름이나 "저희"를 주어로 쓰지 않습니다.
주어는 **"당신"** 이거나, **생략**됩니다.

```
❌ "Milestones Today는 6개의 도구를 제공합니다."
❌ "저희 서비스는 정체성 기반으로 설계되었습니다."

✅ "6개의 도구가 하나의 방향으로 연결됩니다."
✅ "정체성이 먼저 정의됩니다. 그다음이 목표입니다."
```

### 4-3. "~수 있습니다" 를 줄인다

가능성이 아니라 **사실**로 말합니다.

```
❌ "성장의 궤적을 확인할 수 있습니다."
✅ "성장의 궤적이 눈에 보이기 시작합니다."

❌ "정체성을 정의할 수 있습니다."
✅ "정체성이 선명해집니다."
```

### 4-4. 여운을 남기는 법

문장을 완성하지 않거나, 다음 줄과의 간격으로 여운을 만듭니다.

```
✅ "안을 들여다보면."
   (무엇이 보이는지는 말하지 않음 → 스크롤을 유도)

✅ "그 사람이 오늘의 당신에게
    건네는 첫 번째 질문."
   (질문이 뭔지는 말하지 않음 → 궁금증)

✅ "이미 준비된 곳이 있습니다."
   (어디인지는 말하지 않음 → 다음 행동 유도)
```

## 5. 느낌표/이모지/감탄사 규칙

### 느낌표: 사용 금지

```
전체 서비스에서 느낌표(!)는 사용하지 않습니다.
느낌표는 흥분, 세일즈, 가벼움을 연상시킵니다.
고요한 권위는 흥분하지 않습니다.

❌ "지금 시작하세요!"
❌ "놀라운 변화가 시작됩니다!"
✅ "지금, 시작됩니다."
```

### 이모지: 최소한으로

```
UI 내 기능 아이콘:      허용 (✦, ◆, ● 등 기하학적 심볼만)
마케팅 이모지:          금지 (🎉🚀💪🔥 등)
분위기 심볼:           허용 (✦ 정도)
```

### 감탄사: 사용하지 않음

```
❌ "와!" "대박" "정말"
✅ 감탄은 문장의 구조와 여백으로 전달합니다.
```

## 6. 섹션별 톤 강도

페이지 흐름에 따라 톤의 온도가 미세하게 변합니다.

```
히어로          ██████████  가장 강함. 선언. "~하라."
                            어둠 속 첫 빛. 주문을 거는 순간.

문제 제기        ████████░░  담담함. 질문. "~걸까."
                            이미 답을 아는 사람의 질문.

세계관           █████████░  확신. 선언. "~입니다."
                            평행세계를 설명하되, 증명하지 않음.

도구 소개        ███████░░░  차분함. 서술. "~됩니다."
                            각 도구를 경험처럼 예고함.

앱 프리뷰        ██████░░░░  조용함. 최소 텍스트.
                            보여주는 것이 말하는 것보다 많음.

최종 CTA         █████████░  따뜻함 + 확신. "~하세요."
                            유일하게 직접 권하는 순간.
```

## 7. 금지 패턴

### 절대 하지 않는 것

```
1. 과잉 설명
   ❌ "Milestones Today는 정체성 기반의 라이프 디자인 앱으로,
      6개의 도구를 통해 사용자의 목표 설정, 실행 관리,
      성장 추적을 통합적으로 지원하는 서비스입니다."
   
   ✅ "6개의 도구, 하나의 방향."

2. 기능 나열
   ❌ "목표 설정, 습관 트래킹, 진행률 확인, 리마인더,
      통계 대시보드, 커뮤니티 기능을 제공합니다."
   
   ✅ "흩어진 것들이 하나로 연결됩니다."

3. 비교/경쟁
   ❌ "다른 앱과 달리..." "기존 서비스와 차별화된..."
   
   ✅ (비교하지 않습니다. 자기 세계만 말합니다.)

4. 급박함 조성
   ❌ "지금 바로!" "서두르세요!" "한정 수량!"
   
   ✅ "이미 준비된 곳이 있습니다."

5. 과장된 약속
   ❌ "인생이 바뀝니다" "완전히 달라집니다"
   
   ✅ "오늘이 달라지기 시작합니다."
```

## 8. 전체 카피 레퍼런스

아래는 이 가이드를 적용한 전체 카피입니다.

### 히어로

```
FROM THE OTHER SIDE OF YOU

미래의 나를
오늘로 소환하라.

당신의 가장 바람직한 모습은
이미 어딘가에 존재하고 있습니다.

그 사람이 오늘의 당신에게
건네는 첫 번째 질문.

[소환을 시작하다 →]
사전 신청 시 가장 먼저 초대합니다
```

### 문제 제기

```
THE QUESTION

원하는 삶은 그려지는데,
왜 오늘은 달라지지 않는 걸까.

목표를 세우고, 루틴을 만들고, 앱을 깔아도
2주면 잊혀지는 건 의지의 문제가 아닙니다.

순서가 달랐을 뿐입니다.
목표보다 정체성이 먼저입니다.
```

### 세계관

```
THE OTHER SIDE

어딘가의 당신은
이미 그 삶을 살고 있다.

가장 바람직한 삶을 사는 또 다른 당신.
그 사람의 정체성, 습관, 선택, 방향.

Milestones Today는 그 존재를
오늘의 당신에게 연결하는 도구입니다.
```

### 6개 도구

```
6 TOOLS, ONE DIRECTION

6개의 도구,
하나의 방향.

흩어진 목표를 정체성으로 묶고,
오늘의 실행으로 연결합니다.
```

### 각 도구 설명

```
BIND · 나의 축, 재정의
내가 진짜 원하는 것이 무엇인지,
여기서 처음으로 선명해집니다.

BUILD · 체계 설계
목표가 실행 가능한 구조로 나뉘고,
나만의 시스템이 만들어집니다.

BE · 되어가기
매일의 작은 실행이 쌓이면서,
되고 싶은 내가 되어갑니다.

PULSE · 오늘의 점검
오늘 하루가 방향에 맞았는지,
조용히 확인하는 시간입니다.

CONTRACT · 나와의 계약
미래의 나와 약속을 맺습니다.
실행에 무게가 생깁니다.

MIRROR · 거울 들여다보기
변화하고 있는 나를 눈으로 확인합니다.
성장의 궤적이 보이기 시작합니다.
```

### 앱 프리뷰

```
APP PREVIEW

안을 들여다보면.

당신의 방향, 실행, 성장이
하나의 화면에 담겨 있습니다.
```

```
BEGIN YOUR SUMMONING

지금,
첫 번째로 만나보세요.

평행세계의 당신이 기다리고 있습니다.
먼저 오신 분께 가장 먼저 문을 열겠습니다.

[이메일 입력]  [소환을 시작하다 →]

✦ 스팸 없이, 초대와 소식만 전합니다.
```
