## 1. 브랜드 퍼스낼리티

### 핵심 5가지 속성

| 속성 | 설명 | 반대 (피할 것) |
|------|------|---------------|
| **신비로운** | 의식·소환의 언어, 미지에 대한 경외감 | 평범한, 설명적인 |
| **선언적** | 망설임 없이 단언하는 어조 | 소극적, "~할 수 있어요" |
| **과학적** | BPS·심리학 근거를 자연스럽게 녹임 | 과장된, 근거 없는 |
| **직접적** | 빙빙 돌리지 않고 핵심을 먼저 | 장황한, 설명 과다 |
| **공감적** | "당신의 이야기"임을 먼저 증명 | 냉정한, 거리감 있는 |

## 2. 보이스 스펙트럼

```
[신비로운 / 의식적]  ←────────────────────→  [과학적 / 논리적]
        ↑                                              ↑
   히어로, CTA                              증거 섹션, FAQ
   "소환이 시작됩니다"                       "TCI 기반 진단"
```

## 4. 카피 패턴

### 패턴 A — "문제 → 해결"이 아닌 "발견 → 변화"

```
❌ 목표 달성이 어렵다면 The Pulse를 사용해보세요.

✅ 열심히 살고 있는데,
   이게 내 삶인지 확신이 없다.
   
   → 그 감각이 시작점입니다.
```

### 패턴 B — 선언문 형태 (강한 첫 문장)

```
소환이 시작됩니다.
미래의 나와, 지금의 내가 만납니다.
오늘의 선택이 내일의 나를 만들고 있습니다.
```

### 패턴 C — 숫자 + 의미 (Endel 벤치마크 스타일)

Endel: "#1 for increasing focus vs playlists"처럼 숫자를 앞세우되,
The Pulse는 수치 뒤에 철학적 의미를 연결한다.

```
50년
Mental Bank 임상 데이터가 쌓아온 원리

5분
당신의 패턴을 읽기에 충분한 시간

1개
오늘 당신에게 필요한 핵심 질문
```

### 패턴 D — 질문으로 공명 만들기

```
혹시 이런 적 있으신가요?
목표를 세웠는데, 그게 진짜 내 목표인지 의심된다.
열심히 하는데 뭔가 계속 어긋나는 느낌이 든다.
```

## 5. 섹션별 톤 가이드

### 히어로 섹션

**톤**: 의식적 선언, 경외감, 진입의 긴장감  
**금지**: 제품 설명, 기능 나열, 가격 언급

```
예시 헤드라인:
소환이 시작됩니다.
앱이 곧 열립니다.
문이 열립니다.
```

### CTA 버튼

**원칙**: "신청하기"보다 "발견하기". 클릭 저항 최소화.

```
✅ 나의 Pulse 유형 알아보기 →
✅ 소환 시작하기
✅ 포털 열기
✅ 지금 입장하기
❌ 무료로 시작하기
❌ 다운로드
❌ 신청하기
```

### 서브카피 / 본문

**톤**: 가볍고 숨쉬는 문장. 짧게 끊고, 여백을 많이.

```
✅ APEX BPS 시스템을 탑재한 Milestones.today 앱은
   현재 마지막 준비 단계에 있습니다.
   얼리 액세스 신청자에게 가장 먼저 문을 엽니다.
   
❌ APEX BPS 시스템을 기반으로 한 Milestones.today 앱이
   곧 출시 예정입니다. 얼리 액세스를 신청하시면 선착순으로
   사용이 가능하며 다양한 혜택을 받으실 수 있습니다.
```

### 배지 / 레이블 (소문자 금지, 대문자 + 자간)

```
COMING SOON
BETA ACCESS
EARLY ADOPTER
PULSE ACTIVATED
준비 중입니다  (한국어는 그대로)
```

### 푸터

**톤**: 브랜드 철학을 함축한 한 문장

```
© 2026 Milestones.today · Protect Your Future Self
```

## 7. Endel 분석 적용 인사이트

### Endel이 보여준 것

- "We live in an over-stimulating world" — **공통의 문제**로 공감 먼저
- "Backed by neuroscience" — **근거**를 강하게 선언
- "Personalized soundscapes" — **개인화**를 핵심 가치로 전면에
- "Try Today" / "Begin" — **마찰 없는 CTA**, 짧고 직접적

### The Pulse에 적용

| Endel 언어 | The Pulse 대응 언어 |
|-----------|------------------|
| "We live in an over-stimulating world" | "열심히 살고 있는데, 이게 내 삶인지 확신이 없다" |
| "Backed by neuroscience" | "50년 임상 원리, 한국형으로 재설계" |
| "Personalized soundscapes" | "나에게 맞게 세팅된다" |
| "Try Today" | "소환 시작하기" / "나의 Pulse 유형 알아보기" |
| "Begin" | "시작하다" / "열다" |

## 8. 금지 사항 요약

```
× 과도한 수식어 ("완전히", "정말로", "엄청난")
× 수동태 ("만들어졌습니다", "제공됩니다")
× 긴 문장 (1문장 = 1생각)
× 기능 나열형 카피 ("A, B, C를 할 수 있습니다")
× 자기 과시 ("최고의", "유일한", "압도적인")
× 불필요한 경어 과잉 ("~해드립니다", "~이십니다")
```
